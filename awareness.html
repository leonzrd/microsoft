Security Awareness

This was a security awareness simulation

No password was collected during this test. This exercise was designed to help demonstrate how convincing phishing emails and sign-in pages can appear.

When reviewing unexpected emails or sign-in prompts, take a moment to check:

  • The sender's email address and domain.
  • The website address before entering any account information.
  • Unexpected urgency, unusual requests, or unfamiliar sign-in pages.
  • Whether the request can be verified through a trusted channel.

If something feels unusual, report the message to your IT or security team rather than interacting with it.
